# ALSemby v0.2.4 Release Checklist

This file tracks local readiness and Docker Hub publication for the v0.2.4 patch release.

## Scope

- Cover title configuration supports custom main title and subtitle mappings.
- Cover uploads use Emby's base64 image upload path first, which stays effective when StrmAssistant notification enhancement is enabled.
- Manual cover, automatic cover, and Webhook cover flows share the same fixed upload path.
