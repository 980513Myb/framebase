# ALSemby v0.2.3 Release Checklist

## Scope

- Restore the top-right header log shortcut to the lightweight log quick-window.
- Increase TMDB RSS ranking subscription fetch sizes with fixed backend page counts:
  - 5 pages for movie popular, movie top-rated, TV popular, and TV top-rated.
  - 2 pages for movie now-playing, TV on-the-air, trending movie week, and trending TV week.
- Keep TMDB de-duplication; if TMDB repeats items across pages, ALSemby keeps the unique count and does not fetch extra pages.
